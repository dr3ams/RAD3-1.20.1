# Getting Started

The first hour in RAD3 is the most dangerous. Several core systems work differently from vanilla Minecraft, and not knowing about them will get you killed.

This section covers the mechanics you need to understand before anything else: why you are not regenerating health, how your health bar actually works, and how to set up fast travel.
