# Vein Mining and Tree Chopping

Mining whole ore veins and felling entire trees are available as craftable enchantments rather than default behaviours. Both can be toggled on or off at any time.

## How to get them

Both enchantments are gifted to you as part of an early questbook reward — check the Features chapter for the quest. If you missed it, both enchantments are craftable and can be looked up in JEI.

Enchantment books can also be copied using Books of Reprint if you want to apply the same enchantment to multiple tools.

## How to use them

Apply **Vein Mining** to a pickaxe and **Tree Chopping** to an axe using an anvil.

Once applied, the effect is active by default. Press the **grave key** (`` ` ``) while holding the enchanted tool to toggle the effect on or off. The toggle is per-tool and per-session — you can have Vein Mining active on your pickaxe while Tree Chopping is disabled on your axe, or vice versa.

## Practical notes

- Vein Mining breaks connected ore blocks of the same type in a single action. All drops and XP come to you normally.
- Tree Chopping breaks all connected wood blocks above the base of a tree, causing the whole tree to fall at once. Leaves decay normally afterward.
- Both effects have stamina and hunger costs proportional to how much they break in a single use. Large veins and tall trees can drain resources quickly.
- Toggle them off when doing precision mining or building to avoid accidentally breaking more than intended.
