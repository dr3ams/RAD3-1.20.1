# Custom Systems

These systems were built specifically for RAD3 using KubeJS scripting. They do not exist in any mod — they are unique to this modpack.

Each system is self-contained and documented here in full. If something is not working as described, check that you are using the correct item or following the correct procedure — these systems have specific requirements.
