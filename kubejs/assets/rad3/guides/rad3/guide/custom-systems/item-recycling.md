# Item Recycling

The Item Recycling system lets you break down unwanted gear, tools, and equipment into raw materials. Rather than hoarding junk loot or throwing it away, you can convert it into something useful.

## How It Works

Right-click a **Recycler** block with an item you want to break down. The Recycler processes it and returns a set of components based on the item's material composition and quality.

What you recover depends on:
- The **material tier** of the item (wood/stone/iron/gold/diamond/netherite)
- The **item type** (armour returns more material than tools of the same tier)
- Whether the item is **damaged** — heavily damaged items return proportionally less material

Enchanted items can be recycled but enchantments are lost in the process. Use a Grindstone to strip enchantments to a book first if the enchantment is worth keeping.

Returns are not 1:1 — recycling is always a partial recovery, not full material refund. The system is designed for extracting residual value from drops you would otherwise discard.

## Tips

- Recycle low-tier dungeon loot consistently rather than leaving it on the ground
- Diamond and Netherite returns make recycling high-tier dropped gear worthwhile even for partial returns
- Combine with [Book Wyrms](../systems/book-wyrms.md) — strip enchantments at the Grindstone, feed the book to a Wyrm, then recycle the gear
