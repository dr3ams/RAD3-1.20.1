# Passive Skill Tree

The Passive Skill Tree is RAD3's primary character building system. It lets you invest XP levels into permanent stat improvements and unique abilities, shaping your playstyle over time.

## Getting started

Press **O** (default keybind — check Controls if it does not work) to open the skill tree.

You need at least one skill point to begin. Skill points are earned by spending XP levels — each point costs a set number of levels.

## Choosing a class

The first decision you make in the skill tree is your **class**. Choose carefully: **this cannot be changed.** Each class starts with different base nodes and shapes which abilities are cheaply accessible early.

You are not locked out of other classes' nodes permanently — pathing toward them later is possible, but costs significantly more than nodes within your own class tree.

## Navigating the tree

Nodes are connected in chains. You must unlock adjacent nodes before reaching further ones. Each node costs a specific number of skill points.

Nodes provide things like:
- Stat increases (health, speed, attack, armour)
- Reduced cooldowns (combat roll, shield, parcool)
- Unique abilities and passive effects
- Bonuses to specific playstyles (melee, ranged, magic)

## Respeccing

Amnesia Scrolls allow you to reset your skill point allocations. They are obtainable but not trivially so — treat your skill tree choices as semi-permanent rather than freely reversible.
