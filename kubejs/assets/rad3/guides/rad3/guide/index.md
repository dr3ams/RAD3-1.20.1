# RAD3 Field Guide

RAD3 is not a standard Minecraft experience. Natural healing is disabled. The world scales with your power. Preparation before a dungeon run is not optional.

Use the sections below to get your bearings. If you are brand new, start with **Getting Started** — it covers the mechanics most likely to confuse players familiar with vanilla Minecraft.

The **Custom Systems** section documents features built specifically for RAD3 that exist nowhere else — Dungeon Raid and more.
