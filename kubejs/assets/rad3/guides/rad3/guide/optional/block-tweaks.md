# Block and World Tweaks

RAD3 includes a range of quality-of-life improvements to existing Minecraft blocks via Quark and Supplementaries. None of these are systems you need to learn — they are upgrades to things you already know how to use.

## Cauldrons

- Store any liquid, not just water
- Mix potions and dyes
- Boil when a heat source is placed below (boiling cauldrons deal damage to entities inside)
- Stepping into a splash or lingering potion cauldron applies that potion effect
- Throw ingredients into a boiling water cauldron to make stews

## Lecterns

- When holding a Book and Quill, a new GUI exposes a Quill button and Ink Well button
- Click the Ink Well to cycle between font colours
- Click the Quill to cycle between available fonts
- Interact with hoppers for automation

## Lanterns

- Can be hung on walls. Works with any lantern type.

## Hanging Signs

- Can hold any item on both faces
- Can also display banner patterns

## Carpets

- Can be placed on slabs
- Can be placed on stairs

## Cakes

- Can be stacked by placing two on top of each other. Works with any cake type.

## Lilypads

- Any block can be placed on top of them.

## Mob Skulls

- Can be stacked in any combination
- Candles can be placed on top; the candle leaves a wax overlay on the skull

## Banners and Pots

- Can be placed on ceilings.

## Tripwire Hook

- Shift-click with a tool to hang it on the hook for display.
